# Community conduct

Contributors, maintainers, and users should communicate respectfully, welcome differing experience levels, give constructive feedback, and focus discussion on the project. Harassment, threats, discrimination, sexual harassment, doxxing, and publishing another person's private information are not acceptable.

Maintainers may edit or remove inappropriate content and restrict participation when needed. Enforcement should be proportionate and respect the privacy of affected people. Maintainers are held to the same standard.

For a private conduct concern, use a maintainer's private contact channel listed on their GitHub profile; the current code owner is [jazztong](https://github.com/jazztong). Do not post private evidence or identifying details in a public issue. Security vulnerabilities should use the separate reporting channel in [SECURITY.md](SECURITY.md).
